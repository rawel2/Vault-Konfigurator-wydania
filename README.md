# Konfigurator VAULT – wydania / releases

Program do konfiguracji wież z pojemników **VAULT** firmy USSA Design (https://www.ussadesign.com/pages/vault):
lista plików STL z ilościami, elementy niedrukowane, szacunek czasu i filamentu, płyty 3MF dla drukarki
i wizualizacja 3D. Działa lokalnie na Windows, bez internetu.

To repozytorium zawiera tylko gotowe wydania. **Pliki STL/PDF VAULT nie są częścią programu** – kupisz je
u producenta, a program poprosi o ich folder.

## Instalacja

1. Pobierz `instaluj.bat` z [najnowszego wydania](../../releases/latest).
2. Uruchom go. Instalator sprawdzi Pythona (w razie braku zaproponuje instalację), pobierze program, zainstaluje
   numpy, utworzy skrót „Konfigurator VAULT” na pulpicie i uruchomi konfigurator.
3. W oknie „Pliki STL systemu VAULT” wskaż folder z rozpakowanymi plikami VAULT.

Aktualizacja: uruchom `instaluj.bat` ponownie – ustawienia zostają.

---

A configurator for **VAULT** storage towers by USSA Design: STL file list with quantities, hardware, print time and
filament estimate, 3MF plates and a 3D view. Runs locally on Windows, offline.

This repository holds only the releases. **The VAULT STL/PDF files are not included** – buy them from the maker;
the program asks for their folder.

## Installation

1. Download `instaluj.bat` from the [latest release](../../releases/latest).
2. Run it. It checks Python (offers to install it), downloads the program, installs numpy, creates the
   "Konfigurator VAULT" desktop shortcut and starts the configurator.
3. In the "VAULT STL files" window, point to the folder with the unpacked VAULT files.

Update: run `instaluj.bat` again – your settings are kept.
